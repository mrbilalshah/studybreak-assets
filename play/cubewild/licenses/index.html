Cubewild licences

Cubewild is Classroom Connect's browser edition of Mineclonia 0.124.0 running on the Luanti engine, built with luanti-wasm. The game files are unmodified; Classroom Connect only adds the start page. Source code for every part is at the links above.

Cubewild is a fan-made game and is not affiliated with, or endorsed by, Mojang or Microsoft.
